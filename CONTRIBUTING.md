# Contributing

This is a Pursuit.org Builder team project with a fixed 7-week MVP
timeline. Current contributors: Marc Delsoin, Chris Wozniak, Naquan
Mckune.

## Workflow

1. Open an issue or reference the relevant item in
   `RootSync-Tetherless-Project-Docs/decisions/README.md` before
   starting non-trivial work
2. Branch off `main`
3. Open a PR using the template in `.github/PULL_REQUEST_TEMPLATE.md`
4. At least one other team member reviews before merge

## Before the stack is chosen

Hold off on adding dependencies or scaffolding `src/` until the tech
stack decision is recorded in the docs repo's `decisions/README.md`
— avoid false starts on an unapproved stack.
