# Security Policy

## Reporting a vulnerability

Please report security issues privately to the team (Marc Delsoin,
Chris Wozniak, Naquan Mckune) rather than opening a public issue.
Use GitHub's private vulnerability reporting feature on this repo
once enabled, or contact a team member directly.

## Scope

This is an active 7-week MVP build (pre-kickoff as of this writing).
See `RootSync-Tetherless-Project-Docs/security/` for the full threat
model, incident response plan, and dependency policy — those are
placeholders until the tech stack is chosen, then become real and
load-bearing.
